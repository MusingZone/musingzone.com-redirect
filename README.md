# musingzone.com redirect

GitHub Pages site that sends visitors of `musingzone.com` to [vta.musingzone.com](https://vta.musingzone.com/), the website of [Translate Anywhere](https://github.com/MusingZone/vscode-translate-anywhere). The page keeps the requested path, so `musingzone.com/x` opens `vta.musingzone.com/x`.
